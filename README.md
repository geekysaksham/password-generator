# 🔐 Password Generator

A simple Password Generator built using **HTML, Tailwind CSS, and JavaScript**. It allows users to generate random passwords with customizable length and character options.

## 🚀 Features

* Generate random passwords
* Customize password length
* Include uppercase letters
* Include lowercase letters
* Include numbers
* Include special characters
* Copy generated password easily
* Clean and simple user interface

## 🛠️ Technologies Used

* **HTML5**
* **Tailwind CSS**
* **JavaScript**

## 📂 Project Structure

```text
Password-Generator/
│
├── index.html
├── script.js
└── README.md
```

## 💡 How It Works

The project uses JavaScript to randomly generate a password based on the selected options. Users can choose the password length and the types of characters they want to include.

## ▶️ How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server or directly in your browser.
4. Generate your password and customize it using the available options.
